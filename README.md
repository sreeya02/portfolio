The home page is about 1,700 words, which is over the 1,000 minimum. Proofread everything and make sure it sounds like you.

## 3. Publish free on GitHub Pages
1. On github.com, create a new **public** repository (e.g. `portfolio`).
2. Click **Add file → Upload files** and drag in everything: the HTML files, `style.css`, `site.js`, `resume.pdf`, and the `images` folder.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` / `(root)`, and click Save.
4. After about a minute your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.
5. Open it in an incognito window and on your phone, click every link, then submit the URL on Canvas.

Filenames are case-sensitive on GitHub: `Headshot.JPG` will not match `headshot.jpg`.
